automation-containers
=========

Containers com ferramentas de automação e devops.

Lista de ferramentas
------------

- PostgreSQL versão 15  (Dependência do Sonarqube)
- Sonarqube versão community latest
- jenkins versão LTS
- Rundeck versão 5.18.0


Script para subir os containers
------------

    ./start.sh


Script para destruir os containers
------------

    ./stop.sh
